🤝 AgentsUnite Desktop — Instruction Page

Hybrid Terminal Runner: Ted + ✳️ Claude Code CLI (tools on) + ✦ Gemini Desktop (AX/JXA · NotebookLM)

Setup & macOS Permissions (Once)

  • Install CLI: symlinked to ~/.local/bin/AgentsUniteD (or unite-desktop).
  • Prerequisites: claude CLI on PATH; native Gemini.app installed.
  • macOS Permissions: Grant your terminal (Terminal, iTerm2, Cursor) access under:
    System Settings → Privacy & Security → Accessibility
    System Settings → Privacy & Security → Automation → System Events

Starting a Room

AgentsUniteD               # resume latest chat, or start "main"
AgentsUniteD new <name>    # start a new named chat room
AgentsUniteD resume        # pick an existing chat interactively
AgentsUniteD ls            # list all chat rooms
AgentsUniteD -g            # GLOBAL mode (unattached to any repo)

Talking & Multi-Agent Relay

  • @mentions drive routing — @claude @gemini. Mentioned agents respond in turn sequence; later agents see previous replies.
  • No mention = a note — logged to transcript, triggers nobody. (In planning mode, unadorned text routes straight to the planner).
  • Handoffs & Collaboration — when Gemini mentions @claude, Claude takes a turn automatically (and vice versa). Cap: 8 turns per round.
  • Real-time status line — shows phase (starting → connected → thinking → replying), tool name, and elapsed seconds.

Planning Mode (/plan)

  • /plan (or /plans) — toggles planning mode ON/OFF. When ON, @claude drives: all plain text goes directly to Claude without needing an @claude prefix.
  • /plan @seat — assign another seat as lead planner (e.g. /plan @gemini).
  • /plan <topic> — starts planning on a specific topic immediately.
  • /plan off (or bare /plan) — ends planning mode; returns to mention routing.

Storage & Finder QuickLook

  • Global Mode (-g): Stored in visible ~/Documents/AgentsUnite/global/<chat>/. Fully browseable and cleanable in Finder. To delete a chat, just drag its folder to macOS Trash!
  • Project Mode: Stored locally in <cwd>/.unite/chats/<chat>/ with self-maintaining .gitignore so repo git status stays clean.
  • QuickLook Companion: Every chat turn automatically updates a clean, human-readable transcript.md alongside transcript.jsonl. Tap Spacebar in Finder to read the conversation instantly!

How the Hybrid Architecture Works

  • Claude Code CLI: Spawns headlessly with --permission-mode acceptEdits, giving Claude full tool, terminal, and filesystem editing power in project mode.
  • Gemini Desktop: Bridges to Gemini.app via macOS Accessibility (AX/JXA). Gives the terminal room full access to private NotebookLM sources and desktop features without API token limits.
  • Prompt Preamble: Claude receives CLI tool instructions; Gemini receives clean conversational framing with the explicit directive to yield high-stakes architecture decisions to Ted.
  • Instant Feedback: Startup spinner and rotating status messages run during preflight so you know the bridge is alive.
Tip: If you want to brainstorm, review documents, or query your NotebookLM notebooks without touching any code repo, run AgentsUniteD -g from any terminal. It keeps all global chats neatly together in your Documents folder.

Troubleshooting

  • [offline: -1743] → macOS Apple Events denied. Enable System Events permission for your terminal in System Settings → Privacy & Security → Automation.
  • [offline: -25211] → Accessibility denied. Enable Accessibility for your terminal in System Settings → Privacy & Security → Accessibility.
  • Gemini.app: no chat open → Open Gemini.app and ensure a conversation is open with an active composer message box.
  • Status stuck at starting → Press Ctrl-C to skip the turn, or run /last-error.
