# Antigravity CLI Seat Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> **Execution model for this plan (spec §7):** Claude Code is the conductor; the Antigravity CLI (`agy`) is the workhorse. The conductor turns each task into one `agy --print "<task text>" --mode accept-edits --output-format json --print-timeout 10m` call run from the worktree root. The workhorse writes the tests and the code of a task. It never runs the suite, never commits, never touches git. The conductor runs every `Run:` line, reads the diff, and commits. "done" from the workhorse is not evidence; the diff and the suite are. Every task prompt states the worktree root and uses absolute paths. If the auto-mode classifier denies an `agy` launch, the conductor implements that task itself and says so in the commit body.

**Goal:** The terminal runner's `@gemini` seat runs the Antigravity CLI headlessly by default, on the top Gemini Pro model resolved at launch, with Gemini.app kept as an opt-in.

**Architecture:** Vendor the upstream `agy.js` adapter unchanged; add a `geminiSeat` room key; add a model resolver over `agy models`; branch preflight on the seat; reset a room's stale desktop session once at launch so the preamble is sent; leave the prompt builder, grounding, error logs, and the engine untouched.

**Tech Stack:** Node ≥ 20, ES modules, `node:test` + `node:assert/strict`. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-09-10-agy-seat-design.md` — read it first; this plan implements it section by section.

```js
import { runHeadless } from '../../vendor/agentsunite/lib/proc.js';

// Ted, 2026-09-10: the Gemini seat always defaults to the top Gemini Pro at
// high effort, chosen from `agy models` at every launch. A room's
// models.gemini overrides; this constant is used when the list is unavailable.
export const FALLBACK_GEMINI_MODEL = 'gemini-3.1-pro-high';

const PRO_HIGH = /^gemini-(\d+)\.(\d+)-pro-high$/;

// `agy models` prints one "id<TAB>label" line per model on stdout. Flash tiers,
// third-party ids, and Pro at medium or low effort are never selected.
export function pickTopGeminiModel(stdout) {
  let best = null;
  for (const line of String(stdout ?? '').split('\n')) {
    const id = line.split('\t')[0].trim();
    const m = PRO_HIGH.exec(id);
    if (!m) continue;
    const major = Number(m[1]);
    const minor = Number(m[2]);
    if (!best || major > best.major || (major === best.major && minor > best.minor)) {
      best = { id, major, minor };
    }
  }
  return best?.id ?? null;
}

const fallback = () => ({ model: FALLBACK_GEMINI_MODEL, source: 'fallback' });

// Never throws and never blocks startup for more than timeoutMs.
export async function resolveGeminiModel({ configured, binary = 'agy', run = runHeadless, timeoutMs = 15000 } = {}) {
  if (typeof configured === 'string' && configured.trim()) return { model: configured.trim(), source: 'config' };
  let r;
  try { r = await run({ cmd: binary, args: ['models'], timeoutMs }); }
  catch { return fallback(); }
  if (!r || r.spawnError || r.timedOut || r.code !== 0) return fallback();
  const picked = pickTopGeminiModel(r.stdout);
  return picked ? { model: picked, source: 'agy models' } : fallback();
}
```
